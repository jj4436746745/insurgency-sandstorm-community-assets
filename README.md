# Insurgency: Sandstorm Community Assets

Editable packs for the Sandstorm Mod Editor (UE 4.27.2).

- [Pilotable Little Bird](packs/little-bird/README.md) · [CC0 license](packs/little-bird/LICENSE) · [Download Preview 5](https://github.com/jj4436746745/insurgency-sandstorm-community-assets/releases/tag/little-bird-v0.1.0-preview.5) · [Original preview ZIP](previews/pilotable-little-bird-preview.zip?raw=true)

## Repository folders

- [`previews/`](previews/) keeps existing installable ZIP links available.
- [`scripts/`](scripts/) contains tools that build ZIPs from the editable packs.
- [`packs/`](packs/) contains the editable Unreal assets and installation instructions for each pack.
