# Insurgency: Sandstorm Community Assets

Editable asset packs for the Insurgency: Sandstorm Mod Editor (UE 4.27.2).

## Packs

- [Pilotable Little Bird](packs/little-bird/README.md), a player-flown helicopter with four passenger seats. [Download the preview ZIP](previews/pilotable-little-bird-preview.zip?raw=true) (1.98 MB).

Editable packages live under each pack's `Content/` directory. Preserve those paths when copying a pack into the SDK. The Little Bird preview has passed package and dependency checks. Clean SDK import and gameplay validation are pending.

See [Contributing](CONTRIBUTING.md) for asset changes, validation, and packaging. Each pack documents its own asset credits and reuse terms.
